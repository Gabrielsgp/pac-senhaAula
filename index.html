OPÇÃO 1: DIRETO NO PENDRIVE OU ÁREA DE TRABALHO (MAIS RÁPIDO - 0 CONFIGURAÇÃO)
1. Salve este arquivo como index.html (ou pac-senha.html) no pendrive.
2. Copie para a Área de Trabalho (Desktop) de cada PC Linux ou abra direto do pendrive.
3. Dê dois cliques nele para abrir no Firefox ou Chromium e aperte a tecla F11 (Tela Cheia).
OPÇÃO 2: SERVIDOR NA REDE LOCAL DO LABORATÓRIO (1 PC DISTRIBUI PARA TODOS!)
Se os PCs da escola estiverem na mesma rede (cabo ou Wi-Fi), você não precisa passar o pendrive de máquina em máquina! Todo Linux Educacional já vem com Python instalado:
1. No PC do Professor (na mesma pasta onde está o index.html), abra o Terminal e rode:
hostname -I && (python3 -m http.server 8080 || python -m SimpleHTTPServer 8080)
2. O comando vai mostrar o número de IP do seu PC (exemplo: 192.168.1.50).
3. Nos PCs dos alunos, basta abrir o navegador e digitar: http://SEU-IP:8080
